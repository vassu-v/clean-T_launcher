TLauncher — hardened

Portable build. No ads, no tracking, no bundled offers. Everything stays in this folder.

Play

  1. Log in to your TLauncher or Microsoft account under Accounts (bottom left).
  2. Pick a version in the list at the bottom. Fabric versions work with the mods installer.
  3. Press Install the first time, then Play.

Low-end laptop tips

  • Settings (gear icon) → Memory: about 3000 MB on 8 GB RAM.
  • Settings → on launch: Exit frees the launcher's memory while you play.
  • Run install-mods.bat for Sodium, Lithium and FerriteCore on Fabric.

Folder tools

  • update-tlauncher.bat — safe launcher update, inside this folder only.
  • uninstall.bat — backs up your worlds, then removes this folder.
  • Game files and worlds: data\.minecraft
